Complete Setup Guide

Getting Started with ledgr.

A step-by-step guide written for someone who has never done anything like this before. No experience needed.

◆ ~30 minutes total
◆ Works on Mac & Windows
◆ Free to run locally
📋 What we'll do
  1. Install Node.js — the engine that runs the app
  2. Create your free Plaid account and get API keys
  3. Unzip the project files onto your computer
  4. Open a Terminal (the black window for typing commands)
  5. Install the app's required packages
  6. Set up your Plaid API keys
  7. Run the app for the first time
  8. Connect a test bank account
  9. Access the app from your phone or other devices
  10. Troubleshooting — what to do if something goes wrong
1
Install Node.js
The engine that powers the app — think of it like installing Java to run Java apps
What is Node.js? Node.js lets your computer run JavaScript programs outside of a web browser. The ledgr app is written in JavaScript, so Node.js is required for it to work — similar to how you need a PDF reader to open a PDF file.
ℹ️
Already have Node.js? Skip to Step 2. To check, open a Terminal (see Step 4 for how) and type node --version then press Enter. If you see a number like v20.11.0, you're good.

Go to the official Node.js website in your web browser:

🌐 nodejs.org

You'll see two big green download buttons. Click the one that says "LTS" (it may also say "Recommended For Most Users"). LTS stands for Long-Term Support — it's the stable version.

Once downloaded, open the file (it will be in your Downloads folder). Follow the installer — just click Next → Next → Install through all the screens. You don't need to change any settings.

When the installer finishes, click Finish. Node.js is now installed.

✅
You only need to install Node.js once — ever. You won't need to do this again.
2
Create a Free Plaid Account
Plaid is what connects the app to your bank — it handles all the secure login stuff
What is Plaid? Plaid is a trusted service used by apps like Venmo and Robinhood to securely connect to banks. It handles bank logins so ledgr never sees your actual bank username or password — Plaid acts as the middleman. You need two "API keys" from Plaid, which are like secret passwords that allow ledgr to communicate with Plaid.
💰
It's free! Plaid has a free "Sandbox" mode for testing with fake bank data. You can use this indefinitely for free. We'll start with Sandbox — you can connect real banks later if you want.

Go to the Plaid developer dashboard and create a free account:

🌐 dashboard.plaid.com/signup

Fill in your name, email, and create a password. You may need to verify your email address.

After signing in, Plaid may ask you a few questions about what you're building. You can answer honestly (personal finance app, personal use) or just click through.

Once you're in the dashboard, find your API keys. Look for one of these in the left sidebar or top menu:

  • Team Settings → then click Keys
  • Or look for a menu item called Keys or API Keys

On the Keys page you'll see two important pieces of information. Keep this page open — you'll need to copy these in Step 6.

  • Client ID — a long string of letters and numbers, like 6123abc456def789
  • Sandbox secret — another long string, like abc123def456ghi789jkl
🔒
Keep these private. Treat these like passwords. Don't share them, post them online, or put them in an email. We'll store them in a file that's hidden from the internet.
3
Unzip the Project Files
Extract the ledgr folder to somewhere easy to find

Find the ledgr.zip file — it's likely in your Downloads folder.

🍎 Mac
🪟 Windows

Double-click ledgr.zip. Mac will automatically extract it and create a folder called ledgr right next to the zip file.

Right-click on ledgr.zip and choose "Extract All…" A window will pop up asking where to extract. Just click Extract — it will create a ledgr folder in the same location.

Move the ledgr folder somewhere permanent. We recommend moving it to your Desktop or your Documents folder so you can easily find it later. Don't leave it inside your Downloads folder — things in Downloads sometimes get accidentally deleted.

📁
What's inside the ledgr folder? You'll see two folders: backend (the part that talks to Plaid) and frontend (the part you see in your browser). You don't need to open or change any of these files manually — we'll do everything through the terminal.
4
Open a Terminal
The Terminal lets you type commands directly to your computer — don't worry, we'll tell you exactly what to type
What is a Terminal? A Terminal (also called "Command Prompt" on Windows) is a text-based window where you give your computer instructions by typing. It looks intimidating but you'll only be copying and pasting a few simple commands. Think of it like texting your computer.
🍎 Mac
🪟 Windows

Press Command (⌘) + Space to open Spotlight Search. A search bar will appear in the middle of your screen.

Type Terminal and press Enter. A black or white window will open — this is your Terminal.

You'll see a prompt that looks something like yourname@MacBook ~ %. This means the Terminal is ready for you to type a command.

Press the Windows key (the one with the Windows logo) on your keyboard.

Type PowerShell and you'll see "Windows PowerShell" appear in the results. Click on it to open it.

You'll see a blue or black window with text ending in PS C:\Users\YourName>. This means PowerShell is ready.

💡
On Windows, you can also use Windows Terminal (available in the Microsoft Store) which is a nicer version of the same thing.
5
Navigate to the Ledgr Folder & Install Packages
Tell the Terminal where to find your app files, then download the required libraries
What does "navigate" mean in a Terminal? When you open a Terminal, it starts in your "home" folder. You need to move it into the ledgr folder, like changing directories in File Explorer. The command to change folder is cd which stands for "change directory."

Navigate to your ledgr folder

🍎 Mac
🪟 Windows

The easiest way: type cd (with a space after it) in the Terminal, then drag and drop the ledgr folder from Finder directly into the Terminal window. The path will fill in automatically. Then press Enter.

Or if you put the ledgr folder on your Desktop, type this exactly:

Terminal — Mac
cd ~/Desktop/ledgr

If you put it in Documents instead, use:

Terminal — Mac
cd ~/Documents/ledgr

If you put the ledgr folder on your Desktop, type this exactly:

PowerShell — Windows
cd $HOME\Desktop\ledgr

If you put it in Documents instead, use:

PowerShell — Windows
cd $HOME\Documents\ledgr
✅
After pressing Enter, the prompt should change to show the ledgr folder name. For example on Mac it might show ledgr % — that means it worked.

Install the required packages

What are packages? Packages are pre-built pieces of code that the app relies on — things like the Plaid connection library, the web server, etc. This command downloads them all automatically from the internet. You only need to do this once.

Now type this command and press Enter:

Type this exactly, then press Enter
npm run install:all

You'll see a lot of text scroll by — this is normal! It's downloading everything the app needs. Wait until it finishes and you see the prompt (the blinking cursor) come back. This usually takes 1–3 minutes depending on your internet speed.

⏳
Be patient! The screen may look like it's frozen. As long as you don't see a big red error message, it's still working. Only move on when you see the cursor is blinking and ready for input again.
6
Set Up Your Plaid API Keys
Tell the app your private Plaid credentials — you'll create one hidden file

Create the secrets file

Inside the ledgr folder, open the backend folder. You'll see a file called .env.example. You need to make a copy of it called .env (without the word "example").

🍎 Mac
🪟 Windows

In your Terminal (which should still be in the ledgr folder), type this and press Enter:

Terminal — Mac
cp backend/.env.example backend/.env

Nothing will happen visually — that's fine. The file was created silently.

In your PowerShell window (which should still be in the ledgr folder), type this and press Enter:

PowerShell — Windows
copy backend\.env.example backend\.env

Edit the secrets file

Now open the .env file you just created with a plain text editor.

⚠️
Important: Do NOT use Microsoft Word or Google Docs. Use a plain text editor only. Word adds hidden formatting that will break the file. Use Notepad (Windows), TextEdit (Mac), or any code editor.
🍎 Mac
🪟 Windows

In your Terminal, type this to open the file in TextEdit:

Terminal — Mac
open -e backend/.env

TextEdit will open with the file content.

In PowerShell, type this to open the file in Notepad:

PowerShell — Windows
notepad backend\.env

Fill in your Plaid keys

The file will look like this:

Contents of backend/.env
PLAID_CLIENT_ID=your_client_id_here PLAID_SECRET=your_sandbox_secret_here PLAID_ENV=sandbox PLAID_PRODUCTS=transactions PLAID_COUNTRY_CODES=US PORT=3001 FRONTEND_URL=http://localhost:5173

Replace only the two values shown in yellow below with your actual keys from the Plaid dashboard (the page you left open in Step 2):

  • Replace your_client_id_here with your actual Client ID
  • Replace your_sandbox_secret_here with your actual Sandbox secret

The final result should look something like this (with your real values):

Example of what it looks like filled in
PLAID_CLIENT_ID=6123abc456def789012345 PLAID_SECRET=abc123def456ghi789jkl000 PLAID_ENV=sandbox # ... rest stays the same ...

Save the file (Cmd+S on Mac, Ctrl+S on Windows) and close it.

🔒
Never share the .env file. It contains your private keys. Don't email it, post it online, or upload it anywhere. The app is already set up to keep this file hidden.
7
Run the App for the First Time
Start both the frontend and backend with a single command

Go back to your Terminal window (which should still be in the ledgr folder). Type this command and press Enter:

Type this, then press Enter
npm run dev

You'll see output that looks something like this:

What you should see
🏦 Ledgr backend running → http://localhost:3001/api/health → Plaid env: sandbox VITE v5.x.x ready in 312 ms ➜ Local: http://localhost:5173/ ➜ Network: http://192.168.1.x:5173/
🎉
The app is running! Now open your web browser (Chrome, Safari, Firefox, Edge — any of them) and go to this address:
🌐 http://localhost:5173

Type that address into your browser's address bar (the same bar you'd type google.com into) and press Enter. You should see the ledgr app!

💡
What does "localhost" mean? "localhost" just means "this computer." The app is running on your own computer, not on the internet. Only you can access it (unless you follow Step 9 to open it to other devices on your home network).

To stop the app

Go back to the Terminal and press Ctrl + C (on both Mac and Windows). This stops the servers. The app will no longer be accessible until you run npm run dev again.

Every time you want to use the app

  1. Open a Terminal
  2. Navigate to the ledgr folder: cd ~/Desktop/ledgr (or wherever you put it)
  3. Type npm run dev and press Enter
  4. Open your browser and go to http://localhost:5173
8
Connect a Test Bank Account
Use Plaid's built-in test credentials to try it out safely before using real accounts
What is Sandbox mode? Plaid's Sandbox is a fake bank environment built for testing. It has fake accounts loaded with fake transactions, so you can try everything without connecting a real bank. When you're confident it all works, you can then connect your real bank.

In the ledgr app, click the "Connect a Bank" or "🏦 Connect a Bank" button. A window called Plaid Link will pop up.

In the Plaid Link window, type any bank name in the search box — for example, type "Chase" or "Bank of America" and select it. (In Sandbox mode it doesn't matter which bank you pick — they all use the same test credentials.)

When asked to log in, use these test credentials:

user_good
pass_good

These are Plaid's official test credentials — they work for any bank in Sandbox mode.

If asked for a verification code, type 1234.

Select which accounts to link (select all of them for a fuller demo) and click Continue.

The Plaid Link window will close and you'll return to ledgr. The app will automatically sync your test transactions — you should see accounts and transactions appear!

🎉
Congratulations — ledgr is fully working! You can now create budget categories, assign transactions, and explore all the features.

Ready to connect your real bank?

When you're ready to use real bank data, you'll need to apply for Plaid's "Development" access (still free, just requires approval). Go to dashboard.plaid.com, look for a "Request Development Access" or "Move to Development" option, fill in the form, and Plaid typically approves it within a few hours to a day. Once approved, change PLAID_ENV=development in your backend/.env file and use your Development secret instead.

9
Access from Your Phone or Other Devices
Use the app on any device connected to the same Wi-Fi network
How this works: When the app is running on your computer, any other device on the same home Wi-Fi network can access it using your computer's local IP address — similar to how a shared printer works on a home network. This is not accessible from outside your home.

Make sure the app is running (npm run dev in the terminal). Look at the terminal output — you'll see two lines like this:

➜ Local: http://localhost:5173/ ➜ Network: http://192.168.1.45:5173/

The Network address (the one starting with 192.168…) is what you'll use on other devices.

On your phone or tablet (connected to the same Wi-Fi), open any browser and type that Network address into the address bar — for example http://192.168.1.45:5173.

The ledgr app should load on your phone. You can even add it to your home screen for quick access:

  • iPhone: Tap the Share button (the square with an arrow) → "Add to Home Screen"
  • Android: Tap the three dots menu → "Add to Home Screen"
⚠️
Your computer must be on and running the app for other devices to access it. If you close the terminal or shut down your computer, the app goes offline. It will come back when you run npm run dev again.
🌐
Want it available everywhere, not just your home network? That requires "deploying" the app to a cloud server, which is an advanced step. If you'd like to do this, ask for help — it's very doable and there are free options.

Troubleshooting
Common problems and exactly how to fix them
❌ "command not found: npm" or "npm is not recognized"

This means Node.js didn't install correctly, or the Terminal opened before Node.js was installed.

Fix: Close the Terminal completely, then re-open it. If the error persists, reinstall Node.js from nodejs.org (Step 1) and restart your computer.

❌ "No such file or directory" when using cd

The Terminal can't find your ledgr folder at the path you typed.

Fix: Make sure you put the ledgr folder in the right place. Try the drag-and-drop method: type cd (with a space), then drag the ledgr folder from Finder/File Explorer into the Terminal window, then press Enter.

❌ "PLAID_CLIENT_ID is not defined" or "Invalid API keys"

The app can't find your Plaid keys. Either the .env file wasn't created, or the keys weren't saved correctly.

Fix: Go back to Step 6. Make sure the file is named exactly .env (not .env.txt or .env.example). On Windows, Notepad sometimes adds .txt without telling you — check by enabling "show file extensions" in File Explorer settings.

❌ "Port 3001 is already in use" or "Port 5173 is already in use"

The app is already running in another terminal window, or something else is using that port.

Fix: Press Ctrl+C in any open terminal windows to stop running apps. Then try npm run dev again. If still stuck, restart your computer.

❌ The app loads but "Connect a Bank" does nothing or shows an error

The backend isn't running, or your Plaid keys are wrong.

Fix: Check your terminal — you should see both the backend message (🏦 Ledgr backend running) and the Vite message. If you only see one, stop everything (Ctrl+C) and run npm run dev again from the ledgr folder. Also double-check your Plaid keys in backend/.env.

❌ I can't see the .env file in my file explorer

Files starting with a dot (.) are hidden by default on Mac and Windows.

Mac fix: In Finder, press Cmd + Shift + . (period) to toggle hidden files.

Windows fix: In File Explorer, click the View tab and check the "Hidden items" checkbox.

❌ The app worked before but now shows a blank page

The app servers might not be running.

Fix: Open Terminal, navigate to the ledgr folder, and run npm run dev again. Then refresh your browser.

❌ My phone can't connect to the app (Network address doesn't work)

Your phone and computer need to be on the same Wi-Fi network. Also, some computers have a firewall that blocks incoming connections.

Mac fix: Go to System Settings → Network → Firewall, and either turn it off temporarily or add Node.js as an allowed app.

Windows fix: When Windows asks "Do you want to allow this app through the firewall?" click Allow. If you missed that prompt, search for "Windows Defender Firewall" in the Start menu → Allow an app through firewall → add Node.js.

🆘
Still stuck? Copy the exact error message from your terminal (it will be red text) and ask for help. The more detail you share about what you see on screen, the easier it is to diagnose.
